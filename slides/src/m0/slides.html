Level 4 · Blocks

Repeated groups of layers: building with prefabricated walls instead of bricks

A residual block, a transformer block, an encoder or a decoder is used again and again. In a residual block the layer always runs; a copy of the input also takes a shortcut around it (the "skip connection": the input skips the layer, the layer is not skipped), and the two are added. Try it: an input of 5 plus a layer correction of 0.2 becomes 5.2.

How it learns

Start random, measure the error, nudge every weight, repeat

Try it: one neuron, ŷ = w·x + b, learns temperature from elevation at five stations. It starts from a random w and b. Each step does the same four things, shown with the current numbers:

How is the slope known at the very first step? Doesn't it need two points?
Does this work for any network, or only because it is a line?

For almost any network. A network is a chain of simple pieces (multiply, add, ReLU, sigmoid, softmax, convolution, attention), and each piece has a known derivative. The chain rule multiplies them along the path from the error back to every weight. That is backpropagation; libraries such as PyTorch or JAX do it automatically, still from one point, even for a billion weights.

What is special about the line is the landscape: one bowl, so going downhill always reaches the best answer. A network's landscape has many valleys, so the exact slope is only local. Try it on the . Kinks, hard decisions and black-box models need extra care; Module 6 · Optimization (coming next) covers all of this.

How it learns · the landscape

The slope is exact for any network, but only a line has a single valley

Every building block has a known derivative, and the chain rule links them, so backpropagation gives the exact slope for every weight of any network, from one point. The slope says which way is downhill here. For a line the error is one bowl; for a network it has many valleys.

Try it: the error as one weight changes. Drop balls at random starts; each follows the slope downhill.

Kinks

ReLU's corner at 0 and max-pooling have no slope at one exact point; libraries use a convention. Harmless in practice.

Steps and hard decisions

Rounding, thresholds, argmax, sampling: flat almost everywhere, slope 0. Fixes: smooth versions, straight-through tricks.

Black-box physics

A model code with no derivatives breaks the chain: trial nudges, adjoint models (as in 4D-Var), or differentiable physics.

Mini-batches

Slopes are computed on a few examples at a time: exact for that batch, a noisy estimate for all the data.
