05Convolution in 1D

A three-day filter slides along the rainfall series and reuses the same weights at every step

A convolution takes a short window of the series, multiplies it by a small set of weights (the filter or kernel) and adds the products. Then the window moves one day and the same weights are used again.

yt = w1·xt−1 + w2·xt + w3·xt+1

Worked example: rainfall [0, 2, 8, 3, 0] mm with the filter [1, 1, 1] gives 0 + 2 + 8 = 10, 2 + 8 + 3 = 13 and 8 + 3 + 0 = 11.

  • [1/3, 1/3, 1/3] is a 3-day moving average. It smooths the series.
  • [−1, 0, 1] is a difference: the next day minus the previous day. It is positive when rain is increasing.
  • The filter decides which pattern is detected. In a network the 3 values are learned.

05Convolution in 2D

One 3 × 3 filter scans the whole grid, and its 9 values decide what it finds

At each position the filter multiplies the 9 values under it by its 9 weights and adds them up. Change a weight and the whole output changes.

05Learned vs fixed filters

In a CNN the filter values are weights: training finds them, or you can freeze them

  • Trainable. Filter values start random and gradient descent tunes them like any other weight. You choose the setup (filter size, number of filters, stride, padding). The network learns the values.
  • Rediscovery. First-layer filters of a trained CNN often end up looking like the classic edge and blur presets. The network finds them on its own.
  • Frozen filters are set by hand and excluded from training: a Sobel edge layer as fixed preprocessing; physics-informed finite-difference stencils that compute gradients or the Laplacian of a climate field; wavelet scattering networks (Mallat), with fixed wavelet filters; transfer learning, which freezes pretrained filters and trains only the top layers.
  • Middle ground. Start from a known filter such as Sobel and let training fine-tune it.

06Dilated convolution

Skipping days lets the same few weights see much farther back

A dilated filter leaves gaps between the inputs it reads. Dilation d means it reads every d-th day. The number of weights stays the same; the span grows.

yt = w1·xt + w2·xt−d + w3·xt−2d

Example: a 3-weight filter with dilation 2 on daily rainfall covers days t, t−2 and t−4.

Stacking. Filters of size 2 with dilations 1, 2, 4 and 8 see 16 days with only 8 weights. Without dilation each layer adds one day, so 16 days would need 15 layers. WaveNet uses this doubling.

07Transposed convolution

Each coarse value is spread through the filter into a larger grid: learned upsampling

A transposed convolution runs the other way. Each input value multiplies the whole filter, and the result is added into a larger output. With a 2 × 2 filter and stride 2, a coarse 2 × 2 precipitation grid becomes 4 × 4.

  • It adds no real information. The fine grid only rearranges the 4 coarse numbers. Fine detail has to come from learned patterns or extra inputs such as topography.
  • Checkerboard artifacts appear when the filter size is not a multiple of the stride, so footprints overlap unevenly. A common fix: interpolate, then apply a normal convolution.
  • Link to statistical downscaling: learning to map coarse climate model output to a fine grid, using high-resolution predictors such as elevation.

08Depthwise separable convolution

Filter each channel on its own, then mix channels: the same job with about 6 times fewer weights

A standard convolution looks at space and channels at once: every output channel has its own 3 × 3 filter for every input channel. A depthwise separable convolution splits this in two steps.

  • Depthwise: one 3 × 3 filter per input channel, applied to that channel only.
  • Pointwise: a 1 × 1 convolution mixes the filtered channels into the outputs.
standard: k·k·Cin·Cout   separable: k·k·Cin + Cin·Cout

Example: 3 channels in, 16 out, 3 × 3: standard 3 × 3 × 3 × 16 = 432 weights; separable 3 × 3 × 3 + 3 × 16 = 27 + 48 = 75 (biases ignored). About 6 times fewer.

08b1 × 1 convolution

A 1 × 1 filter ignores the neighbours and mixes the variables at each pixel

At every pixel it takes the channel values and forms a weighted sum with learned weights. It is a dense layer applied at every pixel with the same weights.

y = 0.5·T + 0.3·H + 0.2·W

Example: a pixel with temperature 25 °C, humidity 0.8 and wind 4 m/s gives 12.5 + 0.24 + 0.8 = 13.54. Every pixel gets the same recipe.

  • Reduce channels (256 → 64) to cut computation.
  • Mix channels after a depthwise convolution.
  • Match shapes for residual connections.
A spatial filter answers “what pattern is around here?” A 1 × 1 filter answers “how do my variables combine right here?”
