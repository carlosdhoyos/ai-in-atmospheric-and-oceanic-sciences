25Mixture of experts

A router sends each day to a few specialist experts, so a huge model stays cheap per prediction

y = Σk ∈ top‑K gk(x) · Ek(x),   g = softmax(Wr · x)

The router is a tiny dense layer. It scores every expert for the current input, keeps the top K, and turns their scores into weights that sum to 1. Only those K experts run. Their outputs are mixed with those weights.

Here each day of a synthetic year at a Medellín-like station has two router features: a seasonal signal (high in the two rainy seasons, April–May and October–November) and the recent rain (7-day mean, standardized).

  • The router weights are learned like any other weight. Nobody tells it "dry season goes to expert 1". After training it often finds that split by itself.
  • Press Untrained router: random router weights give an arbitrary split, often one expert takes nearly every day. Press Trained router: the experts line up with the seasons.
  • Turn up the recent-rain weight and the split follows wet spells instead of the calendar.
Many parameters, cheap predictions. Total parameters grow with the number of experts; the work per prediction grows only with K.

26State space models (e.g. Mamba)

A state space model is a learned linear filter that carries one small state through a very long sequence

ht = A · ht−1 + B · xt,   yt = C · ht

A says how much of yesterday's state survives, B how much of today's input enters, C how the state is read out. Feed a single pulse (an impulse) and watch the response:

  • 0 < A < 1: the pulse decays. A near 1 means long memory.
  • A > 1: the response explodes. Training keeps A inside (−1, 1).
  • A < 0: the sign flips every step.
  • A smooth oscillation needs two coupled states (a complex A: size and angle).

This is the classic AR(1) or IIR filter from signal processing, with A, B, C learned. Selective SSMs (Mamba) let each input set B and the step size Δ: a heavy-rain day can overwrite the memory, a quiet day leaves it alone.

Linear cost. One update per step: cost grows like L. Attention compares every pair of steps: cost grows like L².

27Fourier neural operator

An FNO layer moves a field to frequencies, reweights a few low modes, and moves it back

A temperature anomaly on 8 points around a latitude circle. Wind carries it east one point per day and mixing smooths it. Task: predict tomorrow from today.

u(x) = 2 + cos x + 0.5·cos 3x
  1. FFT: the field is exactly mode 0 = 2, mode 1 = 1, mode 3 = 0.5.
  2. Keep low modes (0 and 1): a low-pass filter, 2 + cos x.
  3. Multiply by complex weights: mode 0 × 1; mode 1 × 0.8 at −45° (damp to 80%, shift east one point).
  4. Inverse FFT: 2 + 0.8·cos(x − 45°). The peak moves from point 0 to point 1.
  5. Local path and activation: add 0.1·u (fine detail the truncated modes lost), then apply the activation.
Global in one layer. Hover an output point: lines show how much every input point contributes. A convolution would only see its neighbours.

27Fourier neural operator · training

From (today, tomorrow) pairs alone, each mode's weight converges to the true shift and damping

Synthetic pairs from a toy advection–diffusion model on the 8-point circle: shift east one point per day; damp mode 1 to 0.8 (higher modes are damped more, 0.8k²); add small noise. Training is a least-squares fit per mode: Wk = Σ ŷk·ûk* / Σ |ûk|².

  • Physics in disguise. A shift needs a convolution filter as wide as the shift, but only one multiplication per mode here. Damping too. That is why FNOs suit transport and diffusion.
  • Resolution. Weights belong to modes, not grid points: the same weights work on 16 or 64 points.
  • Global view. Every output point depends on the whole input field in one layer.
  • Limit. Only the kept modes are learned. Sharp fronts and extremes need the local path or more modes.
