The key idea. For any single week, some dense weight matrix gives exactly the same output as attention, but no single dense matrix works for every week. Attention is like a dense layer whose weights are rewritten for each input by a small network inside it. Inside, it still uses dense layers: the query, key and value projections. Here the similarity is simply how close the rain amounts are; a trained layer learns its own scoring ().
