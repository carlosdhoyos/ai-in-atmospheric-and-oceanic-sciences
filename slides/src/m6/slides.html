Train and test · when to stop

Training error always falls; the test error tells you when the network starts memorizing

Five students are held out: the network never trains on them (and the scaling uses the 15 training students only, as in Module 1). A big network (8 neurons) keeps lowering its training error, but at some point its error on the held-out students turns back up. Stopping there is early stopping.

Different random starts

Same data, same network, same training: four random starts, four different answers

Each map is the same 3 → hidden → 1 network trained for 1,500 steps on the same 20 students. Only the random starting weights differ. Training goes downhill from wherever it starts, and a network's error landscape has many valleys (Module 0), so each start can settle in a different one.

Activation:
What to look for. Where the students are, the maps mostly agree and the errors are similar. Far from any student they can disagree completely: the data does not decide there. With no activation every start gives the same straight boundary: the network can only draw a straight line, and there is one best line.

In practice: train several times and compare, or average several networks (an ensemble), and do not trust a network far from its training data.
