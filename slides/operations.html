01Weighted sum (the neuron)

A neuron multiplies each input by a weight, adds them up and adds a bias

z = w1x1 + w2x2 + b  →  p = σ(z)

Will it rain in Medellín tomorrow? Humidity 0.8 and pressure drop 0.5, with weights 2 and 3 and bias −2: z = 1.6 + 1.5 − 2 = 1.1, a positive rain signal. The sigmoid turns 1.1 into 0.75, a 75% chance of rain.

You already know this model. Without an activation, one neuron is linear regression. With a sigmoid, it is logistic regression.

02Element-wise operations

Element-wise operations apply the same arithmetic to every cell on its own

out[i, j] = a[i, j] ∘ b[i, j]

Each output cell depends only on the same cell of the inputs. No neighbours, no mixing. The grid is a synthetic 18 × 14 field over Colombia.

  • Add: temperature + 1 °C everywhere.
  • Scale: rainfall × 0.5 halves every cell.
  • Mask: field × land mask keeps land cells (× 1) and zeroes the sea (× 0).
  • Add a field: two grids of the same shape, cell by cell.
Shapes must match, or broadcast. One number, or one row, is stretched across the whole grid without a warning. That is convenient, and a common source of silent bugs: a row of 14 values added to an 18 × 14 grid works, even if you meant one value per row.

03Activation functions

An activation bends each value on its own, so stacked layers can learn curves

Without a nonlinearity, any stack of layers equals one linear layer. The activation is applied to every value independently.

Dying ReLU. If a neuron's input is always negative, ReLU always outputs 0 and its gradient is 0. The neuron stops learning for good.
Saturation. Far from 0, sigmoid and tanh are flat. The gradient almost vanishes, so learning slows. Inputs should be scaled first.

03Activation functions: softmax

Softmax turns a list of scores into probabilities, and the scale of the scores matters

pi = ezi / Σj ezj

A rain-type classifier gives scores for tomorrow: dry 2, normal 1, wet 0. Softmax gives about [0.67, 0.24, 0.09]. The outputs are positive and sum to 1.

Multiply the same scores by 10: [20, 10, 0] gives almost [1, 0, 0]. The order is the same, but the exponential makes the largest score take nearly everything. Dividing by a temperature does the reverse and flattens the probabilities.

Softmax depends on scale, not only on order. The same knob controls how sharp attention is and how random text generation is.

05Convolution in 1D

A three-day filter slides along the rainfall series and reuses the same weights at every step

A convolution takes a short window of the series, multiplies it by a small set of weights (the filter or kernel) and adds the products. Then the window moves one day and the same weights are used again.

yt = w1·xt−1 + w2·xt + w3·xt+1

Worked example: rainfall [0, 2, 8, 3, 0] mm with the filter [1, 1, 1] gives 0 + 2 + 8 = 10, 2 + 8 + 3 = 13 and 8 + 3 + 0 = 11.

  • [1/3, 1/3, 1/3] is a 3-day moving average. It smooths the series.
  • [−1, 0, 1] is a difference: the next day minus the previous day. It is positive when rain is increasing.
  • The filter decides which pattern is detected. In a network the 3 values are learned.

05Convolution in 2D

One 3 × 3 filter scans the whole grid, and its 9 values decide what it finds

At each position the filter multiplies the 9 values under it by its 9 weights and adds them up. Change a weight and the whole output changes.

05Learned vs fixed filters

In a CNN the filter values are weights: training finds them, or you can freeze them

  • Trainable. Filter values start random and gradient descent tunes them like any other weight. You choose the setup (filter size, number of filters, stride, padding). The network learns the values.
  • Rediscovery. First-layer filters of a trained CNN often end up looking like the classic edge and blur presets. The network finds them on its own.
  • Frozen filters are set by hand and excluded from training: a Sobel edge layer as fixed preprocessing; physics-informed finite-difference stencils that compute gradients or the Laplacian of a climate field; wavelet scattering networks (Mallat), with fixed wavelet filters; transfer learning, which freezes pretrained filters and trains only the top layers.
  • Middle ground. Start from a known filter such as Sobel and let training fine-tune it.

05Channels: how filters combine

Filters run side by side; their maps stack into channels; the next layer reads them all

  • Within a layer, in parallel. All 4 filters look at the same input, independently. Each makes its own map; their order does not matter.
  • Stacked. The 4 maps are kept together as one block, 16 × 16 × 4: each pixel now has 4 numbers instead of 1, one per filter. Each layer of the block is a channel, like the red, green and blue of a photo, the bands of a satellite image, or temperature, rain and elevation on one grid.
  • Across layers, in sequence. A layer-2 filter has one 3 × 3 slice per channel (3 × 3 × 4) and adds them all up, so it can combine "vertical edge here" and "horizontal edge here" into "corner here".

Try it: click a pixel in any map.

06Dilated convolution

Skipping days lets the same few weights see much farther back

A dilated filter leaves gaps between the inputs it reads. Dilation d means it reads every d-th day. The number of weights stays the same; the span grows.

yt = w1·xt + w2·xt−d + w3·xt−2d

Example: a 3-weight filter with dilation 2 on daily rainfall covers days t, t−2 and t−4.

Stacking. Filters of size 2 with dilations 1, 2, 4 and 8 see 16 days with only 8 weights. Without dilation each layer adds one day, so 16 days would need 15 layers. WaveNet uses this doubling.

07Transposed convolution

Each coarse value is spread through the filter into a larger grid: learned upsampling

A transposed convolution runs the other way. Each input value multiplies the whole filter, and the result is added into a larger output. With a 2 × 2 filter and stride 2, a coarse 2 × 2 precipitation grid becomes 4 × 4.

  • It adds no real information. The fine grid only rearranges the 4 coarse numbers. Fine detail has to come from learned patterns or extra inputs such as topography.
  • Checkerboard artifacts appear when the filter size is not a multiple of the stride, so footprints overlap unevenly. A common fix: interpolate, then apply a normal convolution.
  • Link to statistical downscaling: learning to map coarse climate model output to a fine grid, using high-resolution predictors such as elevation.

08Depthwise separable convolution

Filter each channel on its own, then mix channels: the same job with about 6 times fewer weights

A standard convolution looks at space and channels at once: every output channel has its own 3 × 3 filter for every input channel. A depthwise separable convolution splits this in two steps.

  • Depthwise: one 3 × 3 filter per input channel, applied to that channel only.
  • Pointwise: a 1 × 1 convolution mixes the filtered channels into the outputs.
standard: k·k·Cin·Cout   separable: k·k·Cin + Cin·Cout

Example: 3 channels in, 16 out, 3 × 3: standard 3 × 3 × 3 × 16 = 432 weights; separable 3 × 3 × 3 + 3 × 16 = 27 + 48 = 75 (biases ignored). About 6 times fewer.

3 channels (synthetic 6 × 6 fields) → 16 outputs

08b1 × 1 convolution

A 1 × 1 filter ignores the neighbours and mixes the variables at each pixel

At every pixel it takes the channel values and forms a weighted sum with learned weights. It is a dense layer applied at every pixel with the same weights.

y = 0.5·T + 0.3·H + 0.2·W

Example: a pixel with temperature 25 °C, humidity 0.8 and wind 4 m/s gives 12.5 + 0.24 + 0.8 = 13.54. Every pixel gets the same recipe.

  • Reduce channels (256 → 64) to cut computation.
  • Mix channels after a depthwise convolution.
  • Match shapes for residual connections.
A spatial filter answers “what pattern is around here?” A 1 × 1 filter answers “how do my variables combine right here?”

Synthetic 6 × 6 fields. Click any pixel to follow it.

09Recurrence (simple RNN)

A recurrent cell reads one day at a time and carries a memory forward

ht = tanh(a · ht−1 + b · xt)

Worked example: a = 0.5, b = 1, h₀ = 0, rainfall [1, 0, 2]. Day 1: tanh(1) = 0.76. Day 2: tanh(0.38) = 0.36. Day 3: tanh(0.18 + 2) = 0.97.

  • a is the memory weight: high a keeps the past, low a forgets fast.
  • b is the input weight: how strongly today's rain pushes the state.
  • The same a and b are reused at every step.
Vanishing memory. With a = 0.5, a past day's influence roughly halves each step: 0.5¹⁰ ≈ 0.001 after 10 days. LSTMs were built to fix this. Saturation: tanh flattens out, so inputs above about 3 all give nearly 1.

10Gated recurrence (LSTM, GRU)

Gates are valves that decide what the memory keeps, adds and releases

ct = f · ct−1 + i · gt    ht = o · tanh(ct)
  • Forget f: share of last month's memory kept (0.9 keeps 90%).
  • Input i: how much of this month's rain signal g is added; a wet month opens it.
  • Output o: how much memory is released as the output h.

How long a storm stays in memory (months after it)

An LSTM is a composite of weighted sums, sigmoid gates, tanh, multiply and add, used as one layer (Module 3). A GRU does the same with two gates. Toy cell, hand-set weights, synthetic data; f is held at the slider value.

11Self-attention

Each word scores every word, softmax turns scores into weights, and the output is a weighted average

  • Query: what am I looking for? Key: what do I contain? Value: what do I pass on? Each comes from its own learned dense layer.
  • Score = q · k / √d, with d the vector length, so softmax does not become too sharp.
w = softmax(q·k / √d)    out = Σ wj vj

Example: "it" against [the, cat, sat, tired] has scores [0, 3, 1, 2]. Softmax gives ≈ [0.03, 0.64, 0.09, 0.24], so "it" takes its meaning mostly from "cat".

Cost grows with the square of the length. Every element scores every other one.
This is what motivates state space models (operation 26).

11bMulti-head attention

Several heads attend in parallel, each to a different kind of relation

Each head has its own query, key and value weights. The head outputs are concatenated and mixed by a dense layer.

A vector of 512 numbers split into 8 heads of 64. Each head works on its 64-number slice.

  • Head 1: the last few days (persistence).
  • Head 2: the same date last year (seasonality).
  • Head 3: days with a similar pressure pattern (analogues).
One head makes one weighted average and can focus on one kind of relation. Several heads look at several relations at once for about the same cost.

11cCausal masking

A causal mask stops each day from attending to the future

Before the softmax, scores for future positions are set to minus infinity, so their weights become exactly 0. Each day attends only to itself and the past.

scoret,s = −∞  for s > t

Example: day 3 has scores [1, 2, 0.5, 3, 4] for days 1 to 5. Mask days 4 and 5, then softmax over [1, 2, 0.5] ≈ [0.23, 0.63, 0.14], and 0 for days 4 and 5.

Data leakage, built into the architecture. Module 1 warned against letting future information into the inputs. The mask enforces that rule inside the model. It is also what lets language models and forecasting transformers generate one step at a time.

12Cross-attention

A station's forecast attends to the satellite cells upwind of it

In cross-attention the queries come from one sequence and the keys and values from another. Here the query is a station, and the keys and values are the cells of a satellite cloud field over Colombia.

w = softmax(qstation · kcell)   out = Σ w · vcell

A trained model learns that clouds arriving at the station come from upwind. Here the score is set by hand: it falls with distance and rises for cells in the direction the wind comes from.

13Graph message passing

Each station updates itself from the messages of its neighbours

hi ← α · hi + (1 − α) · meanj ∈ N(i) hj

Stations are nodes, edges say who talks to whom. Station A has 10 mm and neighbours with 20 and 30 mm: new A = 0.5 · 10 + 0.5 · mean(20, 30) = 17.5 mm. Real graph networks put learned weights on the messages; this keeps only the averaging.

  • After k rounds a station holds information from stations k hops away (ringed on the map).
  • Too many rounds and every station looks alike: over-smoothing. Watch the spread fall.

Rain gauges over Colombia as a graph (synthetic values, mm)

14Pooling

Pooling summarizes each neighbourhood with one number and has no weights

Slide a window over the grid and keep its maximum (max pooling) or its mean (average pooling). With a 2 × 2 window and stride 2 a 4 × 4 grid becomes 2 × 2.

  • No weights: nothing to learn, only a fixed rule.
  • Shift tolerance: if the peak moves inside its window, the max does not change.
  • Global average pooling averages the whole map. Many CNNs use it to turn a stack of maps into one feature vector.

15Upsampling and downsampling

Shrink a field to see context, grow it back to draw a detailed map

  • Downsampling: pooling or a strided convolution keeps one value per f × f block.
  • Upsampling: copy the nearest value, interpolate (bilinear), or learn the weights with a transposed convolution.
  • U-Net shrinks a precipitation field to capture context, then grows it back to a pixel-level map. Skip connections bring the fine detail across.

16Flatten and reshape

Flatten and reshape move numbers around without changing any of them

A 2 × 2 grid becomes a list of 4, and reshaping brings it back:

[[1, 2],[3, 4]]→ 1234→ [[1, 2], [3, 4]]
  • No arithmetic, no weights. Only the shape label changes.
  • Flatten turns a map from a convolution into a vector a dense layer can read.
  • The order is a convention. Row-major (NumPy, PyTorch) reads row by row. Mix conventions and the map is scrambled.
A 4 × 4 grid holds 16 numbers whatever its shape: 4 × 4, 1 × 16 or 2 × 8.

18Positional encoding

Attention ignores order, so each position gets its own wave pattern

PE(pos) = [ sin(pos), cos(pos) ]
  • Each position gets a unique pattern. Real models use many sine–cosine pairs at different frequencies and add them to the inputs.
  • It is a Fourier basis: fast waves tell neighbours apart, slow waves give the coarse place in the sequence, like the harmonics in spectral analysis.

19Batch normalization

Batch norm rescales each feature to mean 0 and std 1 using the examples in the batch

x̂ = (x − μbatch) / √(σ2batch + ε)  ·  y = γ x̂ + β

Rainfall in a batch of 3 days: [0, 10, 20] mm. The mean is 10 mm and the standard deviation is 8.16 mm.

  • γ (scale) and β (shift) are learned, one pair per feature, so the network can undo the normalization if that helps.
  • The statistics come from the batch, so they are noisy when the batch is small. Try 4 days on the right.
At prediction time there may be one example, not a batch. The layer then uses running averages of the mean and std saved during training. ε (e.g. 0.001) avoids dividing by zero when every value in a batch is equal, like a batch of dry days.

20Layer normalization

Layer norm does the same arithmetic on a row of the table, so it works with a batch of one

x̂i = (xi − mean(x)) / √(var(x) + ε)  ·  yi = γ x̂i + β

One example with 3 features: [2, 4, 6]. Mean 4, std 1.63, so it becomes [−1.22, 0, 1.22]. Then scale 2 and shift 1 give [−1.45, 1, 3.45].

Batch norm normalizes a column: one feature across examples. Layer norm normalizes a row: all features of one example. Transformers and RNNs use layer norm because it does not depend on the batch.

21Residual connections

A skip connection adds the input back, so the layer only has to learn the correction

output = x + layer(x)
  • Doing nothing is easy: if the best move is to pass x unchanged, the layer just outputs 0.
  • Direct gradient path: the + passes the gradient straight back, which is what makes networks with 100+ layers trainable (ResNet).
  • Shapes must match to add. If the layer changes the number of channels, a 1×1 convolution on the skip adjusts them.

22Concatenation

Concatenation stacks two sets of features side by side, so the size grows

[a ; b] = [a1 … a8, b1 … b4]

8 satellite features + 4 station features = 12 features. A dense layer of 4 neurons on top then has 12 × 4 + 4 = 52 weights.

  • Concatenation keeps both sets separate: 8 + 4 → 12 values. The next layer learns how to mix them.
  • Residual addition merges them: 4 + 4 → 4 values. Sizes must match.
  • U-Net concatenates encoder maps with decoder maps of the same size, so fine detail lost by downsampling comes back.

23Gating

A gate multiplies a signal by a learned value between 0 and 1, like a valve

y = g ⊙ x,   g = sigmoid(w·x + b) ∈ (0, 1)

Gate 0.1 passes 10% of a value: 20 mm × 0.1 = 2 mm. Gate 1 passes everything, gate 0 blocks everything.

  • The multiply is element-wise: every value has its own gate.
  • Usually the gate is computed from the input itself, so the network decides how much passes at each step.
LSTM and GRU () are built from gates: a forget gate decides how much memory to keep, an input gate how much new rain information to write, an output gate how much to show.
input rainoutput = g × raingate g (right axis)

24Dropout

Dropout switches off random neurons during training and scales up the survivors

yi = mi · xi / (1 − rate),   mi ∈ {0, 1}

With rate 0.5, [4, 2, 6, 8] can become [8, 0, 12, 0] (one possible random draw). Survivors are multiplied by 1 / (1 − 0.5) = 2, so the expected total stays the same.

  • Each step trains a different thinned network. The full network at prediction time acts like an average of all of them.
  • No neuron can rely on one partner, so the model cannot memorize a single shortcut.
  • Off at prediction time: every neuron is on and nothing is scaled.

25Mixture of experts

A router sends each day to a few specialist experts, so a huge model stays cheap per prediction

y = Σk ∈ top‑K gk(x) · Ek(x),   g = softmax(Wr · x)

The router is a tiny dense layer. It scores every expert for the current input, keeps the top K, and turns their scores into weights that sum to 1. Only those K experts run. Their outputs are mixed with those weights.

Here each day of a synthetic year at a Medellín-like station has two router features: a seasonal signal (high in the two rainy seasons, April–May and October–November) and the recent rain (7-day mean, standardized).

  • The router weights are learned like any other weight. Nobody tells it "dry season goes to expert 1". After training it often finds that split by itself.
  • Press Untrained router: random router weights give an arbitrary split, often one expert takes nearly every day. Press Trained router: the experts line up with the seasons.
  • Turn up the recent-rain weight and the split follows wet spells instead of the calendar.
Many parameters, cheap predictions. Total parameters grow with the number of experts; the work per prediction grows only with K.

26State space models (e.g. Mamba)

A state space model is a learned linear filter that carries one small state through a very long sequence

ht = A · ht−1 + B · xt,   yt = C · ht

A says how much of yesterday's state survives, B how much of today's input enters, C how the state is read out. Feed a single pulse (an impulse) and watch the response:

  • 0 < A < 1: the pulse decays. A near 1 means long memory.
  • A > 1: the response explodes. Training keeps A inside (−1, 1).
  • A < 0: the sign flips every step.
  • A smooth oscillation needs two coupled states (a complex A: size and angle).

This is the classic AR(1) or IIR filter from signal processing, with A, B, C learned. Selective SSMs (Mamba) let each input set B and the step size Δ: a heavy-rain day can overwrite the memory, a quiet day leaves it alone.

Linear cost. One update per step: cost grows like L. Attention compares every pair of steps: cost grows like L².

27Fourier neural operator

An FNO layer moves a field to frequencies, reweights a few low modes, and moves it back

A temperature anomaly on 8 points around a latitude circle. Wind carries it east one point per day and mixing smooths it. Task: predict tomorrow from today.

u(x) = 2 + cos x + 0.5·cos 3x
  1. FFT: the field is exactly mode 0 = 2, mode 1 = 1, mode 3 = 0.5.
  2. Keep low modes (0 and 1): a low-pass filter, 2 + cos x.
  3. Multiply by complex weights: mode 0 × 1; mode 1 × 0.8 at −45° (damp to 80%, shift east one point).
  4. Inverse FFT: 2 + 0.8·cos(x − 45°). The peak moves from point 0 to point 1.
  5. Local path and activation: add 0.1·u (fine detail the truncated modes lost), then apply the activation.
Global in one layer. Hover an output point: lines show how much every input point contributes. A convolution would only see its neighbours.

27Fourier neural operator · training

From (today, tomorrow) pairs alone, each mode's weight converges to the true shift and damping

Synthetic pairs from a toy advection–diffusion model on the 8-point circle: shift east one point per day; damp mode 1 to 0.8 (higher modes are damped more, 0.8k²); add small noise. Training is a least-squares fit per mode: Wk = Σ ŷk·ûk* / Σ |ûk|².

  • Physics in disguise. A shift needs a convolution filter as wide as the shift, but only one multiplication per mode here. Damping too. That is why FNOs suit transport and diffusion.
  • Resolution. Weights belong to modes, not grid points: the same weights work on 16 or 64 points.
  • Global view. Every output point depends on the whole input field in one layer.
  • Limit. Only the kept modes are learned. Sharp fronts and extremes need the local path or more modes.

What to remember

Each operation encodes an assumption: dense assumes nothing, convolution assumes locality, recurrence assumes order, attention lets the content decide, graphs follow given links, Fourier operators work on whole fields. Normalization and residual connections keep deep stacks trainable; dropout only acts in training.
