Level 1 · Data foundation

The network only sees numbers, so good models start with the table

Measure, clean, encode, scale, split, and watch for leakage, bias and missing values. Example: rain gauges and satellite rainfall; the student table with estrato and municipality.

Try it. Two students have no absence count. Pick how to fill the gap. Then try the two leakage switches.

Level 2 · Operations

The basic mechanisms, each with an assumption about the data

Weighted sum, activation, convolution, recurrence, attention, normalization, residual connections and more. Example: a 3 × 3 filter sliding over a temperature map finds edges, like a front, or here the slopes of the Andes.

Level 3 · Layers

Operations packaged with their own trainable weights, stacked in order

We stack layers; the output layer is shaped by the task. Try it: stack layers like blocks. Each new layer shows its output shape and parameter count, and the total updates as you go.

Level 4 · Blocks

Repeated groups of layers: building with prefabricated walls instead of bricks

A residual block, a transformer block, an encoder or a decoder is used again and again. In a residual block the layer always runs; a copy of the input also takes a shortcut around it (the "skip connection": the input skips the layer, the layer is not skipped), and the two are added. Try it: an input of 5 plus a layer correction of 0.2 becomes 5.2.

Inductive bias

Every choice encodes an assumption about who connects to whom

Dense: none. Convolution: nearby things matter. Recurrence: order and memory. Attention: anything can relate to anything. Graph: the connections are given.

Try it: the same 5 rainfall days wired five ways. Lines show who connects to whom; thickness is the weight.

How it learns

Start random, measure the error, nudge every weight, repeat

The weights start random. Compare predictions with the truth, measure the error, and nudge every weight a little in the direction that reduces it. Repeat many times.

Try it: one neuron, y = w·x + b, fitting temperature against elevation at five stations.
